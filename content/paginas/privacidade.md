## Quem cuida dos seus dados

Este site é de **Dilce Laranjeira (Laranjeira Atelier)**, que é a responsável pelos dados pessoais descritos aqui, como prevê a Lei Geral de Proteção de Dados (Lei nº 13.709/2018, a LGPD).

[PREENCHER: CNPJ do Laranjeira Atelier, se houver]

Para qualquer assunto de privacidade, escreva para **dillaranjeira@gmail.com**.

## Que dados coletamos e para quê

O site só recebe dados pessoais quando você usa o formulário de contato. Nele você informa **nome, e-mail, assunto e mensagem**. Usamos esses dados só para responder ao seu contato e, se for o caso, conversar sobre a encomenda, o projeto ou a compra que você pediu.

Não usamos seus dados para enviar propaganda e não os vendemos nem repassamos para esse fim.

## Por que podemos usar esses dados

Quando você pede um orçamento, uma encomenda ou informações sobre compra, usamos os dados para atender a esse pedido que você mesmo fez (LGPD, art. 7º, inciso V). Nos demais contatos, a base é o seu consentimento, dado ao enviar o formulário (art. 7º, inciso I). Você pode retirar o consentimento quando quiser, pelo e-mail acima.

## Com quem os dados são compartilhados

Usamos dois serviços para o site funcionar:

- **Cloudflare**: hospeda o site, faz a verificação anti-robô do formulário (Turnstile) e conta as visitas (Web Analytics).
- **Resend**: entrega por e-mail a mensagem que você escreve no formulário.

Essas empresas tratam os dados só para essas funções. Elas podem processar e guardar dados em servidores fora do Brasil.

## Por quanto tempo guardamos

O site não guarda as mensagens em nenhum banco de dados: quando você envia o formulário, a mensagem é repassada por e-mail e não fica armazenada no site.

A mensagem fica na caixa de e-mail da Dilce enquanto for útil para a conversa. O Resend, que entrega o e-mail, guarda uma cópia do envio por até 30 dias, segundo as regras dele.

## Cookies e outros registros no seu navegador

- **O site não grava cookies.**
- **Página do portfólio:** para você voltar de um projeto e encontrar a página como deixou, o site guarda no seu próprio navegador o filtro escolhido e a posição na página. Esse registro não é enviado a ninguém e é apagado quando você fecha a aba.
- **Verificação anti-robô (Turnstile):** aparece só no formulário. Ela analisa dados técnicos do navegador, como endereço de IP e tipo de navegador, apenas para diferenciar pessoas de robôs. Do jeito que usamos, ela gera um código de uso único para o envio e não grava cookie. O cookie que o Turnstile pode gravar (chamado `cf_clearance`) só aparece com um recurso que não usamos.
- **Estatísticas (Cloudflare Web Analytics):** contam visitas de forma geral, sem cookies e sem guardar nada no seu navegador.

## Seus direitos

Pela LGPD, você pode pedir a qualquer momento:

- para saber se temos dados seus e quais são;
- para corrigir dados incompletos ou errados;
- para apagar seus dados;
- informações sobre com quem eles foram compartilhados.

Basta escrever para **dillaranjeira@gmail.com**. Respondemos o quanto antes. Se não ficar satisfeito, você também pode procurar a Autoridade Nacional de Proteção de Dados (ANPD).
